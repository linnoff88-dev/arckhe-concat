Em resumo

O Concat é um programa gratuito para editar vídeo, feito como alternativa ao CapCut. Serve para quem faz Reels, Shorts, TikTok, vídeos do YouTube, tutoriais e cortes de podcast. Ele faz o que se costuma abrir o CapCut para fazer (cortar, legendar, narrar com voz de IA, tirar o fundo, animar), mas sem cobrar, sem pedir conta e sem mandar seus vídeos para a internet. Basta instalar no Windows, Mac, Linux ou Android; os modelos de IA são baixados uma vez e depois funcionam sem internet.

O que é

Tudo que você usa no CapCut, sem as pegadinhas

Projeto de código aberto do desenvolvedor Jareer (jub0t/Concat, licença AGPL-3.0), com mais de 5 mil estrelas no GitHub. Este repositório é a cópia (fork) do INEMA para estudo, com o guia em três idiomas.

🚫 Sem marca d'água, sem conta

Grátis para sempre: nada de assinatura, login ou recurso trancado atrás de pagamento.

🔒 100% local

Nada é enviado para a nuvem. Legendas (Whisper), vozes e recorte de fundo rodam na sua máquina, inclusive sem internet.

🤖 Agentes também editam

Tem API JSON-RPC, gRPC e MCP, além de uma linha de comando. Um script ou agente de IA pode cortar vídeo com ele.

💬 Legendas automáticas

Whisper local: você escolhe o tamanho do modelo e as legendas já entram estilizadas na linha do tempo.

🗣️ Voz por IA e clonagem

Vozes locais grátis ou qualquer voz a partir de alguns segundos de gravação.

🧍 Remove o fundo

Pessoas, objetos, ou você mesmo pinta a máscara.

🎞️ Keyframes

Posição, escala, rotação, opacidade, volume e parâmetros de efeito, com editor de curvas.

✨ 170+ efeitos

Filtros, transições e animações de texto renderizados na GPU, ao vivo na prévia.

📤 Exporta até 4K 60

H.264, HEVC e AV1, com cor de 10 bits. Áudio com limpeza de voz num botão.

Como funciona

Do arquivo ao vídeo pronto, sem sair do seu disco

Um motor nativo em Rust com compositor na GPU faz o trabalho pesado: proxies, decodificação por hardware e prévia fluida mesmo em 4K. A janela do editor é feita em Slint.

Instalar→ Arrastar o vídeo→ Cortar na linha do tempo→ Legenda · voz · fundo→ Efeitos e títulos→ Exportar

Para pessoas

O editor com linha do tempo magnética, várias faixas e várias linhas do tempo no mesmo projeto. Em 25 idiomas, incluindo português.

Para máquinas

concat-cli com probe, render, api (JSON-RPC pela entrada padrão) e serve (a mesma API num socket em 127.0.0.1:7420). O MCP está na documentação do autor.

Guia de uso · passo a passo

Seu primeiro vídeo no Concat

Versão atual: 0.2.7 (beta, outubro de 2026). Funciona, mas ainda tem arestas.

1

Baixe o instalador

O jeito mais fácil: abra o site oficial concatenate.pages.dev e clique em Download. Ele entrega o arquivo certo para sua máquina. No Linux dá para baixar também pelo terminal.

# site oficial (Windows, Mac, Linux, Android)
https://concatenate.pages.dev/

# Linux ARM (ex.: DGX Spark), pelo terminal
gh release download v0.2.7 -R jub0t/Concat -p '*linux-aarch64.deb'
sudo apt install ./Concat-0.2.7-linux-aarch64.deb

# Linux x86_64: troque aarch64 por x86_64 (há .deb, .rpm e .AppImage)
2

Libere o app se o sistema reclamar

As versões ainda não são assinadas. No Windows, no aviso do SmartScreen clique em Mais informações › Executar assim mesmo. No Mac:

xattr -dr com.apple.quarantine /Applications/Concat.app
3

Baixe os modelos de IA uma vez

Em Configurações, escolha o tamanho do modelo de legendas (Whisper) e as vozes. Modelo maior acerta mais e pede mais máquina.

# no app
Configurações › Modelos › Baixar
4

Arraste o vídeo e corte

Solte o arquivo no projeto e na linha do tempo. Dividir, aparar, ripple, juntar, congelar quadro e mudar velocidade. Ligue a linha do tempo magnética se quiser.

5

Legende, narre e tire o fundo

Gere as legendas automáticas e ajuste o estilo; crie narração com voz local ou clone uma voz com poucos segundos de áudio; remova o fundo de uma pessoa ou objeto. Para o som, um botão faz a limpeza da voz e nivela o volume.

6

Exporte

Escolha H.264 (mais compatível), HEVC ou AV1, até 4K 60 com cor de 10 bits. Sem marca d'água.

7

Opcional: rode pelo código e pela linha de comando

Para estudar o motor ou deixar um agente editar. Comandos do próprio repositório:

git clone https://github.com/inematds/concat && cd concat/src
cargo run -p concat                          # o editor (modo debug)
cargo run -p concat-cli -- probe video.mp4     # lê as informações do arquivo
cargo run -p concat-cli -- render video.mp4 out.mp4 --frames 120
cargo run -p concat-cli -- api '{"method":"catalogue.list","kind":"filter"}'
cargo run -p concat-cli -- serve             # API JSON-RPC em 127.0.0.1:7420

Documentação da API e do MCP (em inglês): concatenate.pages.dev/docs.
